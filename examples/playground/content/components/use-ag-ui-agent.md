Takes any `@ag-ui/client` agent (`HttpAgent`, or a framework integration's own `AbstractAgent`) and turns its messages and events into AI SDK message parts, so every component works with it unchanged, approvals included. Interrupts bound to a tool call become approval cards, and `respond` resumes the run: each interrupt takes one answer, and a resume that fails or is stopped before it finishes asks again, with the reason for a failure in `error`, unless the call's tool already ran: its interrupt then stays in `interrupts`, for `resolve`. [AG-UI agents](/docs/ag-ui) has the event mapping, LangGraph and the pure functions behind the hook.
